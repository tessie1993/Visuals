# Music Visualizer (Web Port)

This project has been ported to the Web using React, Vite, and the Web Audio API. 
The original Android Native C++ (JNI) visualization stack was incompatible with the current cloud environment.

## Features
- Real-time microphone audio visualization
- Client-side Web Audio AnalyserNode integration
- React and TailwindCSS UI

## Running
Run \`npm run dev\` to start the visualizer.
